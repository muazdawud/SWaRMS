Welcome to the ESP8266 Server Dashboard

This is a typical Server that provides some basic (like Viewing File, Uploading File) to advance features (like Wireless Firmware Update, Simulating Web Sockets through LED Control) which are all available and ready to be tested.

Features:

  • Firmware Update: This is a feature that allows flashing the board with a new/updated firmware and it usually takes binary files as input.
  • File Upoad: This provides privilages to upload new files/updated (like new HTML /index file) into the LittleFS for storage and usage.
  • Update Credentials: This provide the way in which your device can be configured and set to connect to routers/acess points to access the internet.
  • Control LED: This page provides access and provides features that enable the usage and application of Web Sockets which is a robust protocol in the Internet Protocol as a whole.
  • View File: This is another feature that allows a client to fetch and view files which were stored on the LittleFS.
